## Lancer le projet en local

1. Cloner le dépôt :

   ```bash
   git clone  https://github.com/insrobane4-tech/Portfolio.git
   cd portfolio
   ```

2. Ouvrir `index.html` dans le navigateur, ou utiliser l'extension **Live Server** de VS Code (clic droit sur `index.html` → *Open with Live Server*). Le site s'ouvre alors sur `http://127.0.0.1:5500`.

Aucune installation ni dépendance n'est nécessaire.

---

## Déploiement avec GitHub Pages

1. Pousser le projet sur GitHub.
2. Dans le dépôt, aller dans **Settings → Pages**.
3. Choisir la branche `main` et le dossier `/ (root)`, puis enregistrer.
4. Le site est disponible quelques minutes plus tard à l'adresse  'https://insrobane4-tech.github.io/Portfolio/'
